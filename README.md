# 急救研習室 · First Aid Study Lab

[Open the GitHub Pages study app](https://anthonywck9712.github.io/first-aid-study-web/).

This repository hosts the complete interface: reference reader, practice room, 30-question quizzes and progress/history screens. It contains no textbook data, scans, question bank, registration code, passwords or learner records.

Select **連接私人服務** and complete private-site access in the connection window, then keep that window open. Log into your study account on the GitHub page. New accounts require the instructor's registration code. Learning content becomes available only after verified account login.

The separate backend remains private. An approved learner must have access to that private site; the registration code alone does not grant platform access. The connection window performs allowlisted authenticated requests on its own origin and exchanges responses only with its opening GitHub page. No service access secret is published here.

The original first-aid-study repository and its previous book-data history remain private. Current backend implementation is maintained in its private source repository.

Publish the generated docs/ folder using GitHub Pages, main branch.
